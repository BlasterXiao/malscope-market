## 条目格式

文件名用英文短横线 slug，例如 `process-hollowing.md`。内容按下面的结构写：

```markdown
# <中文名> / <英文名>

- 分类：<ATT&CK 战术对应的中文分类>
- ATT&CK：<编号> <官方英文名>（核对日期 YYYY-MM-DD）

## 原理
3 到 6 句：攻击者面对什么限制，用这个技术绕过了什么，数据或控制流怎么走。

## 机制
参与方和它们之间的可达关系，用列表写清楚，生成记录时据此画图。被阻断的路径单独标出。

## 常见实现
样本里通常怎么写：用到的 API、常量、编码方式、数据结构。

## 在样本里怎么找
用 *sql 插件找证据的思路：查哪些导入的交叉引用、搜哪些字符串或常量、看哪类函数。

## 检测要点
网络侧 / 主机侧 / 样本侧。
```

ATT&CK 编号必须在 https://attack.mitre.org 核对过再写入，并记下核对日期。
