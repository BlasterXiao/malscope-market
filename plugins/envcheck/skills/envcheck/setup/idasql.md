# idasql 本机安装

插件只提供使用说明，下面这些需要每台机器自己装。

## 需要什么

| 项 | 要求 |
|----|------|
| IDA Pro | 9.2 / 9.3 / 9.4，已授权 |
| idasql 程序与插件 | 推荐 0.0.19，与本市场钉住的插件 0.0.19 对应；**构建必须和 IDA 版本一致** |

## 安装步骤

1. 打开 https://github.com/allthingsida/idasql/releases ，选推荐版本，下载与你 IDA 版本对应的包（文件名里带 `ida92` / `ida93` / `ida94`）。Windows 选 `*-plugin.zip`。不同 IDA 版本的构建不能混用。
2. 解压后：
   - `idasql.exe` 放到 IDA 安装目录（例如 `C:\Program Files\IDA Professional 9.2\`）
   - `idasql.dll` 放到 IDA 安装目录下的 `plugins\`（UI 模式需要）
3. 把 IDA 安装目录加入 PATH。
4. 重开终端，验证：

   ```
   where idasql
   idasql --version
   ```

## 两种模式

- **CLI 无头模式**：直接 `/idasql:connect` 指定样本或 .i64，不需要打开 IDA 界面。
- **UI 模式**：在 IDA 里打开样本，在 `idasql>` 提示符执行 `.http start`，会显示地址（如 `http://127.0.0.1:8174`，随机端口在 8100–8999）。用 `.pin set http 8080` 可以固定端口。浏览器打开 `<地址>/status` 能看到状态即正常。

## 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| `where idasql` 找不到 | IDA 目录不在 PATH | 第 3 步 |
| IDA 加载插件失败 | 下载的构建和 IDA 版本不一致 | 重新下载对应 `idaXX` 的包 |
| 查询报表或列不存在 | 程序版本低于插件 | 升级程序到推荐版本 |
