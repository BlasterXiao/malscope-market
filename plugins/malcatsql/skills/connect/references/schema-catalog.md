# Schema Catalog (malcatsql)

Generated by `scripts/gen_catalog.py` from a live malcatsql 0.3.0 session.
**Confirm the live shape with `PRAGMA table_xinfo(<table>);`** before complex queries.

Conventions: every `addr`/`*_addr` column is a **virtual address** (what Malcat prints in
disassembly and pseudo-C; print with `hex()`). It is NULL for locations without a VA
(e.g. overlay bytes). `ea` columns are Malcat's internal effective addresses, and `offset` columns
are file offsets.

## Refresh

```sql
SELECT name, type FROM pragma_table_list WHERE schema IN ('main','temp') ORDER BY type, name;
PRAGMA table_xinfo(<surface>);
```

## `runtime_settings` keys

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| `query_timeout_ms` | int | `120000` | Abort a statement after N ms (0 = no limit) |
| `enable_python` | bool | `False` | Allow malcat_python()/malcat_python_file() |
| `python_output_max` | int | `65536` | Truncate captured Python stdout to N chars |
| `byte_search_max_results` | int | `1000` | Default cap for byte_search rows |
| `max_result_rows` | int | `100000` | Rows returned per statement over HTTP/MCP |
| `collect_max_rows` | int | `1000000` | Workspace collect(): max rows per sample before it refuses (never truncates silently) |

## `capabilities` rows

| Key | Value | Note |
|-----|-------|------|
| `feature.decompiler` | true | decompile()/pseudocode for this architecture |
| `feature.capa` | true | capa / capa_matches (computed on first query) |
| `feature.yara` | true | signatures / signature_hits |
| `feature.python` | false | malcat_python() gate |
| `feature.kesakode` | false | not exposed: online lookups consume quota |
| `feature.persistence` | true | SELECT save() writes a .malcat project |
| `mutation.runtime_settings.update` | true | UPDATE runtime_settings SET value=... WHERE key=... |
| `mutation.funcs.update` | true | UPDATE funcs SET name=... (empty/NULL removes the user label); run is deferred to the next read |
| `mutation.names.insert` | true | INSERT/UPDATE set a user label, DELETE removes it; run is deferred to the next read |
| `mutation.names.update` | true | INSERT/UPDATE set a user label, DELETE removes it; run is deferred to the next read |
| `mutation.names.delete` | true | INSERT/UPDATE set a user label, DELETE removes it; run is deferred to the next read |
| `mutation.comments.insert` | true | persisted by SELECT save() |
| `mutation.comments.update` | true | persisted by SELECT save() |
| `mutation.comments.delete` | true | persisted by SELECT save() |
| `mutation.decompile_aliases.insert` | true | persisted by SELECT save(); malcatsql applies aliases to decompile() output itself |
| `mutation.decompile_aliases.update` | true | persisted by SELECT save(); malcatsql applies aliases to decompile() output itself |
| `mutation.decompile_aliases.delete` | true | persisted by SELECT save(); malcatsql applies aliases to decompile() output itself |

All other `mutation.<table>.<op>` rows are `false`; a write to them fails with that key in the error.
